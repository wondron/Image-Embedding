## 1. 背景与范围

### 1.1 背景

现有单张搜已具备：

- 搜索目标切换：`searchTarget` · **自建库** (`local` → `searchLocalImages` → `POST /api/search`) / **现网 Global** (`global` → `searchImages` → `POST /api/predict/searchImage_*`)
- 查询方式：本地上传 / 图片链接；批量仅走现网（本轮不扩自建批量）
- `lib/search.ts` · `searchLocalImages` **已预留**可选形参 `scoreThreshold`（及 `topK`），但 **App 未传、UI 无控件** → 当前请求省略字段，后端按契约缺省 **0.55**

本轮补齐：**搜索页可调控件**绑定 `score_threshold`，默认展示/提交 **0.55**；可关拒识（显式 `0`）；与自建/现网切换共存。

### 1.2 In Scope（本轮）

- [ ] 拒识控件交互说明（线框级）+ 可勾选验收条
- [ ] 默认 **0.55**；可调范围 **0.30–1**、步进 **0.01**；「关闭拒识」→ 显式传 **`0`**
- [ ] 滑块 **或** 数字输入（可并存）；与 `searchTarget` 切换共存
- [ ] 调阈值后重新搜须带新值；空态 / 加载态行为不变（相对现网壳）
- [ ] 非法值钳制或可读提示；对接 `422` `SEARCH_BAD_SCORE_THRESHOLD`（若漏网）
- [ ] 明确复用 query 面板气质；**不做软删**

### 1.3 Out of Scope（非目标）

- **不做软删 / 硬删** UI 或 API
- 不改批量搜走自建（批量仍仅现网；批量页**不**强制出拒识控件，见 §3.3）
- 不强制本轮实现 `top_k` 控件、scene 切换 UI（契约另有字段；本刀只锁 `score_threshold`）
- 不按附录 B 分 scene 默认档（占位、本轮不强制；UI 默认恒 0.55）
- 不重做结果卡 / 空态 / 加载骨架视觉
- 不实现业务 TS、不装依赖、不 git commit（实现归前端架构）
- 不改契约正文；不改图库 / 入库验收文档本体（仅交叉引用）

## 2. 契约对齐 · §3.2.1 `score_threshold`

**出处**：仓根 `docs/image-search-mvp-data-contract.md` → **§3.2 可选字段表** + **§3.2.1**（拒识 · FE 可调）。

### 2.1 字段语义（摘录 · 验收锁定）

| 项 | 约定 | FE 验收要点 |
| --- | --- | --- |
| 缺省 / 省略 / `null` | **一律视为 `0.55`**（拒识开启）。**禁止**把省略解释成「不过滤」 | 控件初始展示 **0.55**；用户未改时请求可省略字段 **或** 显式传 `0.55`（二选一，推荐**显式传当前控件值**便于抓包验收） |
| 关闭拒识 | 须**显式**传 **`score_threshold=0`** | 「关闭拒识」勾选/开关 → 提交 **`0`**，**禁止**用 omit/`null` 冒充关闭 |
| 可调范围 | **`0.30`～`1`**，步进 **`0.01`**；另允许哨兵 **`0`** | 滑块 min/max/step 对齐；数字输入同约束 |
| 合法集合 | **`{0} ∪ [0.30, 1]`** | `(0, 0.30)`、`>1`、负数、NaN → 不得发出；见 §5.4 |
| 比较 | 保留 **`score >= T`**；严格低于丢弃 | FE 只传阈值；不过滤结果集二次拒识（后端已滤） |
| 作用面 | **仅自建路径**；**不**作用于 FlyB 行 | 现网 Global 请求**不传**本字段（predict 路径无此契约字段） |
| 与 scene | 正交 | MVP 无 scene UI 时固定缺省 normal；阈值控件独立 |
| 与 top_k | 先取 top_k 再滤分；滤后不回补 | 本刀可不做 top_k UI |
| 空 → FlyB | 拒识后空且 scene=normal 可 FlyB | 空态文案/通道徽章沿用现壳；**不**因加控件改空/加载骨架 |
| 硬校验错误 | `422` `SEARCH_BAD_SCORE_THRESHOLD` | 若仍发出非法值 → 错误态可读（见 §5.3） |

**契约 FE 句（原文精神）**：搜索页可调控件绑定本字段；不传控件时走默认 **0.55**；提供「关闭拒识」须显式提交 `0`。

> **跟刀（2026-10-28 · 总裁）**：可调上沿 **0.95→1**。**数据规范已改约**对齐 §3.2.1；本验收卡一律按 **0.30–1**（step 0.01）执行。

### 2.2 请求落点

| 路径 | 是否传 `score_threshold` |
| --- | --- |
| `POST /api/search`（自建 · `searchLocalImages`） | **是**（本刀主路径） |
| `POST /api/predict/searchImage_file\|url`（现网） | **否** |

`search.ts` 已支持：multipart 时 `form.append('score_threshold', String(...))`；JSON 时 `payload.score_threshold = ...`。架构须从 App **传入当前控件值**（含关闭时的 `0`）。

## 3. 现有壳复用说明

路径相对 `frontend/src/`。

### 3.1 主落点

| 现有 | 符号 / 区域 | 本轮建议 |
| --- | --- | --- |
| 查询面板 | `App.tsx` · `.query-panel` / `.query-toolbar` / `.query-body` | **控件落在查询侧**，紧邻「搜索目标」`search-target-tabs` 或「开始搜索」按钮上方/旁；**不**塞进结果区筛选条 |
| 搜索目标 | `searchTarget` · 自建库 / 现网 Global | **共存**：切换目标不销毁拒识控件状态；仅 **自建** 请求携带阈值；切到现网时控件可 **禁用 + 说明「仅自建库生效」** 或灰显保留值 |
| 单张搜 | `runSearch` → `searchLocalImages` / `searchImages` | 自建分支传入 `scoreThreshold` |
| 批量 | `BatchSearchPanel` | **本轮可不加**拒识控件（批量仅现网）；若日后自建批量，另开刀 |
| 结果区 | `.results-panel` / `EmptyResults` / `.loading-state` | **空态/加载态不变**（文案与骨架不因本刀改版） |
| 样式 | `styles.css` token、`.segmented`、`.input`、`.toolbar-select` | 滑块/数字用现有 input 气质；可用 `SlidersHorizontal` 图标（已 import） |

### 3.3 与搜索目标共存规则

| 状态 | 控件 | 请求 |
| --- | --- | --- |
| `searchTarget === 'local'` | 可编辑（除非「关闭拒识」锁定滑块） | `searchLocalImages({ ..., scoreThreshold })` |
| `searchTarget === 'global'` | **禁用**或旁注「仅自建」；**保留**用户上次阈值值，切回自建不丢 | `searchImages` **不传** `scoreThreshold` |
| 切换目标 | 可 `resetResults()`（现壳已如此）；**不要**重置拒识默认，除非产品另定——本验收：**切换目标不重置阈值/关闭开关** | — |
| 批量 Tab | 不展示拒识控件，或展示但注明「批量仅现网，拒识不适用」 | 不传 |

## 4. 交互说明

### 4.1 默认与展示

- 首次进入搜图页：阈值展示 **0.55**；「关闭拒识」**未勾选**
- 数字展示建议固定 2 位小数（`0.55` / `0.30` / `1.00`）；滑块与数字双向同步
- 步进 **0.01**（键盘上下、滑块 step 皆然）

### 4.2 「关闭拒识」

- 勾选后：滑块与数字输入 **disabled**；UI 可显示哨兵文案「已关闭（提交 0）」
- 取消勾选：恢复到勾选前的阈值，若无记忆则回 **0.55**
- 提交：关闭时 **必须** `score_threshold=0`；开启时传当前 ∈ [0.30, 1] 的值

### 4.3 调阈值后重新搜

- 仅改滑块/数字/开关 **不自动发请求**（与现壳「改 URL/换图才 reset、点搜索才请求」一致；避免拖滑块打爆）
- 用户点击「开始搜索」（或等价触发）时，请求体/表单须带 **当前** 阈值
- 验收：抓包连续两次搜索，第一次 0.55、调到 0.70 再搜 → 第二次为 `0.70`；勾选关闭再搜 → `0`
- `busy`/加载中：控件可禁用编辑（与现网搜索中禁用切目标一致），防止半状态

### 4.4 空态 / 加载态（明确「不变」）

- **加载态**：仍用现有 `.loading-state` + skeleton；自建文案「正在自建库中检索…」可保留；**不**因拒识增加第二套 loading
- **空态**：仍用 `EmptyResults` / 现有无结果文案与通道徽章（`source=empty` / flyb / self）；拒识把结果滤空时后端可能走 FlyB 或 empty——FE **按响应展示**，不在空态额外解释算法（可选一行弱提示「可降低拒识阈值后重试」——**增强项，非必验**）
- 本刀验收：**不得**因加控件导致空态/加载布局回归（错位、丢 skeleton、丢 role=status）

## 5. 验收标准（可勾选）

### 5.1 默认与范围

- [ ] 控件初始值为 **0.55**（展示与将要提交的语义一致）
- [ ] 滑块或数字：`min=0.30`、`max=1`、`step=0.01`（关闭模式除外）
- [ ] 「关闭拒识」勾选后，下一次自建搜索请求含 **`score_threshold=0`**（multipart 字段或 JSON 键）
- [ ] 未关闭时，自建搜索请求含当前阈值（如 `0.55` / `0.70`），且值 ∈ [0.30, 1]
- [ ] 合法集合外的值（如 0.20、1.01、负数）**不会**被发出（见 §5.4）

### 5.2 与搜索目标共存

- [ ] 自建 / 现网切换控件仍可用；拒识控件与 tabs **同时存在**于查询面板
- [ ] 现网搜索请求 **不出现** `score_threshold`
- [ ] 自建搜索请求 **出现** `score_threshold`（显式 0 或 0.30–1）
- [ ] 切到现网时拒识控件禁用或等价不可提交；切回自建后阈值与关闭状态保持（不无故回到未定义）

### 5.3 重搜带新值 · 空/加载不变

- [ ] 修改阈值后点击搜索：网络面板可见新值
- [ ] 搜索进行中：加载态与改前一致（骨架/文案区域不回归）
- [ ] 无结果 / 首次未搜：空态与改前一致（不因本刀换成另一套 Empty）
- [ ] 错误条仍走 `.message-banner.message-error`；`422` `SEARCH_BAD_SCORE_THRESHOLD` 时有可读失败信息（可复用 `readableApiError`）

### 5.4 非法值 · 错误态

| 情况 | 期望 |
| --- | --- |
| 用户输入 `0.20`（在 (0,0.30)） | **钳制**到 0.30 **或** 行内提示并阻止搜索；**二选一**，行为稳定可测 |
| 用户输入 `1.2` / 空 / 非数字 | 钳制到 1 / 恢复上次合法值 / 提示；**禁止**发出 NaN 或空串 |
| 关闭拒识 | 只发 `0`，不发 `null`、不省略冒充关闭 |
| 后端仍返回 `SEARCH_BAD_SCORE_THRESHOLD` | 错误态 + 不静默当空结果 |

### 5.5 非目标确认

- [ ] **无**软删 / 删除入口出现在本刀相关 UI
- [ ] 不强制改 BatchSearchPanel 业务行为
- [ ] 不引入新设计体系 token（可用现有 CSS 变量）

## 6. 字段映射速查（给前端架构）

| UI | API（仅自建 `POST /api/search`） |

## 10. 给前端架构的注意点（≤3）

1. **只给自建** `searchLocalImages` 传 `scoreThreshold`；关闭拒识必须传 **`0`**，勿 omit；现网 `searchImages` 不要带该字段。

3. **合法集合** `{0} ∪ [0.30,1]` step 0.01；前端先钳制，空态/加载复用现壳不重做。
